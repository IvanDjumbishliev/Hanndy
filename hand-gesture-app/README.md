# Hanndy

Air-drawing app built with React, TypeScript, Vite, and MediaPipe Hands.

## Run locally

```bash
npm install
npm start
```

Open the local URL printed by Vite and allow camera access. Pinch your thumb and index finger together to draw; make a fist to undo.

## Other scripts

- `npm run dev` — start the Vite development server
- `npm run build` — create a production build
- `npm run preview` — preview the production build
- `npm run lint` — run ESLint
- `npx tsc --noEmit` — type-check the project
